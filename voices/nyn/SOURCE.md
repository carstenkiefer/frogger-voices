# Runyankore (nyn) – origin and license

**No clips yet.** This language is meant to be recorded by native speakers
(see [docs/RECORDING.md](../../docs/RECORDING.md)). The texts in
`texts/nyn.toml` are machine translations and need to be corrected by the
speaker first.

When recordings are added, this file names the speaker (or "anonymous"),
the date, the recording setup and the license (CC0 1.0 or CC BY 4.0, as the
speaker chooses).
